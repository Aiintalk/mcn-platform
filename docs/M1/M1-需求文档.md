# M1 需求文档

> 里程碑：M1 基础底座
> 目标读者：产品经理 / 项目负责人
> 状态：✅ 已交付（2026-06-02）

---

## 一、背景与目标

M1 是整个平台的基础底座，目标是完成**登录鉴权与用户管理**，确保：

- 所有人员必须登录才能使用系统
- 管理员与运营人员看到不同的页面和功能
- 新账号首次登录强制修改密码，保证账号安全
- 管理员可以集中管理团队账号

M1 完成后，M2 数据中台、M3 AI 工具才能在此基础上继续搭建。

---

## 二、用户角色

系统有两种角色，共用同一个登录入口 `/login`，登录成功后自动跳转到对应端：

| 角色 | 中文名 | 登录后进入 | 定位 |
|---|---|---|---|
| `admin` | 管理员 | `/admin`（管理后台） | 维护基础数据、管理账号，不参与日常内容创作 |
| `operator` | 运营 | `/`（业务运营端） | 日常使用 AI 工具进行内容创作，不可进入后台 |

## 三、功能需求

### 3.1 登录

**页面路径**：`/login`

- 账号 + 密码登录，账号为用户名（非邮箱）
- 登录中状态：按钮显示「登录中…」并禁用，防止重复提交
- 登录失败：页面显示红色错误提示
  - 账号不存在 / 密码错误 → 「账号或密码错误」
  - 账号已禁用 → 「账号已停用，请联系管理员」
- 登录成功：按角色自动跳转（admin → `/admin`，operator → `/`）

---

### 3.2 首次登录强制改密

新账号 `passwordChangedAt` 为 `null`，表示从未改过密。系统在以下两种情况触发强制改密：

1. 管理员新建账号后，用户首次登录
2. 管理员重置该用户密码后，用户下次登录

**强制改密页**：`/change-password`

| 字段 | 说明 |
|---|---|
| 当前密码 | 管理员发放的初始密码 |
| 新密码 | 用户自定义，≥ 8 位 |
| 确认新密码 | 与新密码一致 |

**校验规则**：
- 前端：新密码 ≠ 确认密码 / 新密码 < 8 位 → 立即提示
- 后端：当前密码错误 / 新密码与当前密码相同 → 返回 400

**改密成功后**：系统自动登出，跳转 `/login`，用户用新密码重新登录，此后不再强制跳转改密页。

---

### 3.3 路由保护

所有页面和 API 均受 Middleware 保护：

| 条件 | 处理 |
|---|---|
| 未携带有效 JWT | 302 跳转 `/login` |
| `mustChangePassword = true` | 302 跳转 `/change-password`（最高优先级） |
| 运营访问 `/admin/*` 任意路由 | 403 Forbidden |
| 运营调用写操作 API（红人/产品增删改） | 403 Forbidden |
| 通过所有检查 | 正常放行 |

**JWT 有效期**：8 小时，过期后访问任意页面跳回登录。

---

### 3.4 用户管理（管理员端）

**页面路径**：`/admin/users`

管理员可以管理团队所有账号。

#### 新建账号

| 字段 | 规则 |
|---|---|
| 姓名 | 必填，先填姓名 |
| 账号 | 由姓名全拼自动生成（汉字→全拼，数字保留）；重名时追加递增数字；可手动修改 |
| 角色 | 管理员 / 运营，默认运营 |
| 初始密码 | 预填默认密码 `Mcn@123456`，明文显示，可修改；首次登录强制修改 |

账号生成示例：「张三」→ `zhangsan`，「测试1」→ `ceshi1`，重复时 `zhangsan` → `zhangsan1`

#### 重置密码

- 弹窗预填 `Mcn@123456`，明文显示，可修改
- 提交成功后切换为成功反馈页，展示已设置的密码明文，管理员复制后告知用户
- 用户下次登录自动触发强制改密流程

#### 其他操作

| 操作 | 说明 |
|---|---|
| 编辑 | 修改姓名和角色，账号不可改 |
| 禁用 / 启用 | 立即生效；禁用后用户无法登录，数据保留 |
| 删除 | 软删除（status → disabled），账号从列表消失 |

## 四、数据说明

M1 使用以下数据库表：

| 表名 | 说明 |
|---|---|
| `users` | 用户主表，含账号、密码哈希、角色、状态、改密时间等 |

关键字段：

| 字段 | 说明 |
|---|---|
| `username` | 登录账号，全局唯一 |
| `password_hash` | bcrypt 哈希，rounds=12 |
| `role` | `admin` \| `operator` |
| `status` | `active` \| `disabled` |
| `password_changed_at` | `NULL` 表示从未改密，触发强制改密流程 |
| `last_login_at` | 每次登录成功后更新 |

## 五、权限规则

| 功能 | 管理员 | 运营 |
|---|---|---|
| 登录 / 改密 | ✅ | ✅ |
| 访问运营端（`/`、`/kols/*`、`/products/*`） | ✅ | ✅ |
| 访问管理后台（`/admin/*`） | ✅ | ❌ |
| 用户管理（增删改查） | ✅ | ❌ |
| 调用写操作 API | ✅ | ❌ |

---

## 六、不在 M1 范围内

- 忘记密码自助找回（需联系管理员重置）
- 账号创建后修改用户名
- 多因素认证（MFA）
- 登录日志查询页面
