## 技术说明

- **认证方式：** 直接填写登录表单（auth project 不预加载 storageState）
- **权限拦截验证：** 中间件返回 403 JSON 或 302 重定向到 /login，通过 `page.evaluate(() => document.body?.textContent)` 检测
- **强制改密：** `passwordChangedAt = null` 时触发改密流程；首次测试若 admin 已改密则跳过
- **登录限流：** 登录端点设置 30 次/分钟/IP 限制，防止暴力破解
