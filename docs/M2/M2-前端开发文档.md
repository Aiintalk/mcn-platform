## 8. 联调约定

后端接口就绪后，按如下步骤替换 mock：

1. 在 `src/lib/api/` 目录下新建对应的 fetch 函数（`kols.ts` / `products.ts` / `viral-scripts.ts`）
2. 页面组件从 `import { mockKols } from '@/lib/mock/kols'` 改为 `import { fetchKols } from '@/lib/api/kols'`
3. 逐页联调，确认字段映射正确

**API 调用函数示例**

```typescript
// src/lib/api/kols.ts
export async function fetchKols(params?: KolListParams) {
  const searchParams = new URLSearchParams()
  if (params?.page) searchParams.set('page', String(params.page))
  if (params?.status) searchParams.set('status', params.status)

  const res = await fetch(`/api/kols?${searchParams}`)
  if (!res.ok) throw new Error('获取红人列表失败')
  return res.json()
}
```
