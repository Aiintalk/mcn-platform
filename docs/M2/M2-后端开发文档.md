### 2.4 POST /api/kols/[id]/upload-profile

**处理逻辑**

```
接收 multipart/form-data
  → 读取文件 buffer
  → 判断文件类型：
      .docx → mammoth.convertToMarkdown(buffer) → md 字符串
      .md   → 直接读 buffer.toString('utf-8')
  → 查询当前 is_current=true 的版本号 N
  → 将旧记录 is_current 置为 false
  → 插入新记录：version=N+1, is_current=true, soul_md=新内容
  → 返回新版本号
```

**请求**：`Content-Type: multipart/form-data`，字段名 `file`，支持 `.md` / `.docx`

**响应**

```json
{
  "data": {
    "version": 2,
    "message": "人格档案已更新"
  }
}
```

### 3.3 POST /api/products/[id]/upload-selling-points

上传卖点卡文档，解析后结构化写入 `product_selling_points`。

**处理逻辑**

```
接收文件（.docx / .md）
  → mammoth 解析为 md（如果是 docx）
  → 按固定格式抽取三块内容：
      背书段（"背书" 标题下的文本）
      机制段（"机制" 标题下的文本）
      种草段（"种草" 标题下的文本）
  → 旧版本 is_current 置 false
  → 写入新版本
```

> 注意：文档解析采用基于标题关键词的简单分段，不调用 AI。M3 迁入 `selling-point-extractor` 时再接入 AI 结构化能力。

## 6. 权限规则

| 接口前缀 | operator | admin |
|---|---|---|
| `GET /api/kols` / `GET /api/kols/[id]` | ✅ 只读 | ✅ 读写 |
| `POST/PATCH/DELETE /api/kols/*` | ❌ 403 | ✅ |
| `GET /api/products` / `GET /api/products/[id]` | ✅ 只读 | ✅ 读写 |
| `POST/PATCH/DELETE /api/products/*` | ❌ 403 | ✅ |
| `GET /api/viral-scripts` | ✅ 只读 | ✅ 读写 |
| `POST/PATCH/DELETE /api/viral-scripts/*` | ❌ 403 | ✅ |

在 `middleware.ts` 里补充：

```typescript
// M2 新增：写操作只允许 admin
const isWriteOperation = ['POST', 'PATCH', 'PUT', 'DELETE'].includes(req.method)
const isDataRoute =
  pathname.startsWith('/api/kols') ||
  pathname.startsWith('/api/products') ||
  pathname.startsWith('/api/viral-scripts')

if (isDataRoute && isWriteOperation && token?.role !== 'admin') {
  return new NextResponse(
    JSON.stringify({ error: 'Forbidden', message: '数据写操作仅管理员可执行' }),
    { status: 403, headers: { 'Content-Type': 'application/json' } }
  )
}
```
