## 技术说明

- **认证方式：** admin/security project 通过 global-setup 预生成 storageState，无需每次手动登录
- **权限切换：** operator 测试套件通过 `test.use({ storageState: OPERATOR_STATE })` 切换 session
- **自定义弹窗：** 编辑/删除确认弹窗使用 `div.fixed.inset-0`（非 `role="dialog"`），通过 `filter({ hasText: '...' })` 精确定位
- **文件上传：** 通过 `input[type="file"].setInputFiles()` 模拟 .md/.docx/.txt 文件上传
- **API 响应捕获：** 新建爆款时通过 `page.waitForResponse()` 捕获 POST 响应体，获取 scriptId 用于清理
- **爆款库无详情页：** 爆款脚本直接在列表内操作（无跳转链接），不能通过 href 获取 ID
