# 服务器部署文档

> 项目：MCN Platform
> 技术栈：Next.js 14 + PostgreSQL 15 + PM2 + Nginx
> 最后更新：2026-06-02

---

| 项目 | 最低配置 | 推荐配置 |
|---|---|---|
| CPU | 2 核 | 4 核 |
| 内存 | 2 GB | 4 GB |
| 磁盘 | 20 GB SSD | 40 GB SSD |
| 操作系统 | Ubuntu 22.04 LTS | Ubuntu 22.04 LTS |
| 公网 IP | 必须 | 必须 |
| 域名 | 必须（需已备案） | 必须 |

## 二、环境依赖安装

### 2.1 Node.js 20（通过 nvm 安装）

```bash
# 安装 nvm
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
source ~/.bashrc

# 安装并激活 Node.js 20
nvm install 20
nvm use 20
nvm alias default 20

# 验证
node -v   # v20.x.x
npm -v
```

### 2.2 pnpm 9

```bash
npm install -g pnpm@9
pnpm -v   # 9.x.x
```

### 2.3 PM2

```bash
npm install -g pm2
pm2 -v
```

### 2.4 PostgreSQL 15

```bash
# 安装
sudo apt update
sudo apt install -y postgresql-15 postgresql-client-15

# 启动并设置开机自启
sudo systemctl enable postgresql
sudo systemctl start postgresql

# 验证
psql --version   # psql (PostgreSQL) 15.x
```

#### 创建数据库和用户

```bash
sudo -u postgres psql <<EOF
CREATE USER mcn_user WITH PASSWORD '替换为强密码';
CREATE DATABASE mcn_platform OWNER mcn_user;
GRANT ALL PRIVILEGES ON DATABASE mcn_platform TO mcn_user;
EOF
```

> **安全提示**：密码请使用 12 位以上随机字符串，不要使用示例中的占位符。

### 2.5 Nginx

```bash
sudo apt install -y nginx
sudo systemctl enable nginx
sudo systemctl start nginx
```

## 三、SSL 证书

使用阿里云免费 DV 证书（或其他 CA），下载后上传到服务器：

```bash
sudo mkdir -p /etc/nginx/ssl
sudo cp mcn-platform.pem /etc/nginx/ssl/mcn-platform.pem
sudo cp mcn-platform.key /etc/nginx/ssl/mcn-platform.key
sudo chmod 600 /etc/nginx/ssl/mcn-platform.key
```

## 四、项目部署

### 4.1 克隆代码

```bash
cd /opt
sudo git clone <仓库地址> mcn-platform
sudo chown -R $USER:$USER /opt/mcn-platform
cd /opt/mcn-platform
```

### 4.2 安装依赖

```bash
pnpm install --frozen-lockfile
```

### 4.3 配置环境变量

在项目根目录 `/opt/mcn-platform` 创建 `.env.production`：

```bash
sudo nano /opt/mcn-platform/apps/web/.env.production
```

写入以下内容（**替换所有占位符**）：

```env
# 数据库
DATABASE_URL="postgresql://mcn_user:替换为强密码@localhost:5432/mcn_platform?schema=public&connection_limit=10&pool_timeout=20"

# NextAuth
NEXTAUTH_SECRET="替换为随机64位字符串"
NEXTAUTH_URL="https://你的域名"

# Node 环境
NODE_ENV="production"
```

> **生成 NEXTAUTH_SECRET**：
> ```bash
> openssl rand -base64 48
> ```

### 4.4 执行数据库迁移

```bash
cd /opt/mcn-platform
pnpm db:deploy
```

### 4.5 初始化种子数据

```bash
pnpm db:seed
```

种子数据会创建初始管理员账号：
- 账号：`admin`
- 密码：`admin123`（首次登录强制修改）

### 4.6 构建项目

```bash
pnpm build
```

构建产物位于 `apps/web/.next/`，耗时约 2~5 分钟。

## 五、Nginx 配置

### 5.1 部署配置文件

```bash
sudo cp /opt/mcn-platform/nginx/mcn-platform.conf /etc/nginx/conf.d/mcn-platform.conf
```

编辑配置文件，**将所有 `<你的域名>` 替换为实际域名**：

```bash
sudo nano /etc/nginx/conf.d/mcn-platform.conf
```

### 5.2 验证并重载

```bash
sudo nginx -t
sudo nginx -s reload
```

### 5.3 配置说明

| 配置项 | 说明 |
|---|---|
| HTTP 80 → HTTPS 443 重定向 | 已配置 |
| TLS 1.2 / 1.3 | 已启用 |
| `/_next/static/` 静态资源缓存 365 天 | 已配置 |
| `proxy_buffering off` | 为 M3 AI 流式输出关闭缓冲 |
| `client_max_body_size 20M` | 文档上传限制 |
| `proxy_read_timeout 120s` | AI 接口超时时间 |

## 六、PM2 启动应用

### 6.1 首次启动

```bash
cd /opt/mcn-platform
pm2 start ecosystem.config.js --env production
```

### 6.2 设置开机自启

```bash
pm2 save
pm2 startup
# 按提示执行输出的 sudo 命令
```

### 6.3 PM2 配置说明

| 配置项 | 值 | 说明 |
|---|---|---|
| `instances` | 4 | 4 个 worker 进程（集群模式） |
| `exec_mode` | cluster | Node.js 多进程，充分利用多核 |
| `max_memory_restart` | 1G | 单进程超过 1GB 自动重启 |
| 日志输出 | `/var/log/mcn-platform/out.log` | 标准输出 |
| 日志错误 | `/var/log/mcn-platform/error.log` | 错误输出 |

创建日志目录：

```bash
sudo mkdir -p /var/log/mcn-platform
sudo chown $USER:$USER /var/log/mcn-platform
```

## 七、数据库备份

### 7.1 部署备份 Cron

```bash
sudo mkdir -p /backup
sudo chown postgres:postgres /backup

sudo cp /opt/mcn-platform/scripts/mcn-platform-backup.cron /etc/cron.d/mcn-platform-backup
sudo chmod 644 /etc/cron.d/mcn-platform-backup
```

### 7.2 备份策略

| 项目 | 配置 |
|---|---|
| 执行时间 | 每天凌晨 3:00 |
| 备份方式 | `pg_dump` + gzip 压缩 |
| 保留周期 | 最近 7 天 |
| 备份路径 | `/backup/mcn_platform_YYYYMMDD.sql.gz` |
| 清理时间 | 每天凌晨 4:00 |

### 7.3 手动备份（应急）

```bash
sudo -u postgres pg_dump mcn_platform | gzip > /backup/mcn_platform_manual_$(date +%Y%m%d_%H%M%S).sql.gz
```

### 7.4 恢复备份

```bash
# 解压并恢复到数据库
gunzip -c /backup/mcn_platform_20260602.sql.gz | sudo -u postgres psql mcn_platform
```

## 八、常用运维命令

### PM2 应用管理

```bash
pm2 status                  # 查看进程状态
pm2 logs mcn-web            # 实时查看日志
pm2 logs mcn-web --lines 100  # 查看最近 100 行日志
pm2 restart mcn-web         # 重启应用（零停机）
pm2 reload mcn-web          # 热重载（集群模式下滚动重启）
pm2 stop mcn-web            # 停止应用
```

### 更新部署（发新版本）

```bash
cd /opt/mcn-platform

# 拉取最新代码
git pull origin main

# 重新安装依赖（如有变更）
pnpm install --frozen-lockfile

# 执行数据库迁移（如有变更）
pnpm db:deploy

# 重新构建
pnpm build

# 热重载（不中断现有连接）
pm2 reload mcn-web
```

### 数据库连接

```bash
sudo -u postgres psql mcn_platform
# 或使用账号密码
psql -U mcn_user -d mcn_platform -h localhost
```

### Nginx 操作

```bash
sudo nginx -t               # 测试配置
sudo nginx -s reload        # 重载配置（不中断）
sudo systemctl restart nginx  # 完全重启
```

### 查看日志

```bash
# 应用日志
tail -f /var/log/mcn-platform/out.log
tail -f /var/log/mcn-platform/error.log

# Nginx 日志
tail -f /var/log/nginx/mcn-platform-access.log
tail -f /var/log/nginx/mcn-platform-error.log
```

## 九、环境变量一览

| 变量名 | 必填 | 说明 | 示例 |
|---|---|---|---|
| `DATABASE_URL` | ✅ | PostgreSQL 连接字符串（含连接池参数） | `postgresql://mcn_user:xxx@localhost:5432/mcn_platform?connection_limit=10&pool_timeout=20` |
| `NEXTAUTH_SECRET` | ✅ | JWT 签名密钥，64 位随机字符串 | `openssl rand -base64 48` 生成 |
| `NEXTAUTH_URL` | ✅ | 站点完整 URL，含协议 | `https://mcn.yourdomain.com` |
| `NODE_ENV` | ✅ | 运行环境 | `production` |

## 十、部署检查清单

首次部署完成后，逐项验证：

- [ ] `https://你的域名` 可正常访问，自动跳转 HTTPS
- [ ] `/login` 页面正常显示
- [ ] `admin` / `admin123` 登录成功，触发强制改密
- [ ] 改密成功后可正常进入管理后台
- [ ] `/admin/users` 用户列表正常显示
- [ ] `pm2 status` 显示 4 个 worker 均为 `online`
- [ ] `/var/log/mcn-platform/error.log` 无报错
- [ ] Nginx access log 有正常请求记录
- [ ] `/backup/` 目录存在，cron 任务已注册
